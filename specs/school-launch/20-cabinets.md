## 3. Совмещения выводятся из фактов, не из ролей (AR-151)

- **«+ профили своих детей»** у любой штатной роли: существует
  `GuardianLink(guardianCard → student)`, где карточка родителя связана с той
  же учёткой. Отдельная роль `parent` для этого не выдаётся — блок «Мои дети»
  появляется на главной автоматически.
- **«+ журнал своих предметов — если есть»**: существует `TeacherBinding` на
  эту учётку → в своих уроках доступны отметка и тема, независимо от прочих
  ролей. Проверка принадлежности урока — та же, что у `teacher` в 1.1.1.
- Разделение обязанностей по идентичности (AR-61) не ослабляется.

## 4. Дневник (`S-90`, AR-158)

Проекция для `student` и для `parent` (в профиле ребёнка). Ни одной мутации.

- Неделя как школьный дневник: дни → материализованные уроки ребёнка
  (с учётом его группы) → предмет, номер/время слота, тема урока (если
  заполнена), отметка.
- Источник — те же `SchoolLesson`/`Mark`/`JournalRow`, что у журнала: дневник
  не хранит ничего своего (владение данными не меняется, AR-110).
- Колонки ДЗ нет вовсе — появится в инкременте №2, пустая колонка не
  показывается.
- Навигация по неделям — как календарь недель журнала `S-50`; текущая неделя
  открывается автоматически.

Пустые состояния (обязательны, FLOR-ADS §5.21): расписание не подтверждено →
«Расписание ещё не составлено — загляни позже»; уроки есть, отметок нет →
сетка недели без отметок (не выглядит ошибкой); каникулы/нерабочий день →
день помечен, не пуст.

## 5. Рейтинг класса (`S-91`, AR-159 [дефолт])

- Ранжирование учеников класса по **среднему баллу числовых отметок текущей
  четверти** (правило AR-79: «н»/«б» не участвуют). Равный средний — одно
  место. Ученики без отметок — внизу, без места, подпись «пока без отметок».
- Видят: `student` (свой класс, своя строка выделена), `parent` (класс каждого
  ребёнка). Штатным ролям рейтинг не показывается [дефолт] — их инструмент
  журнал.
- Формула — дефолт владельца, обратима без миграции (проекция).

## 8. Словарь экранов

**КПЦ** (контингентно-персональный центр) — собирательное имя контура
«Классы/Ученики (`S-10`–`S-13`) + Персонал (`S-30`–`S-32`) + Родители
(`S-14`)». **УТЦ** — календарь+расписание+журнал (AR-149); панель управления
УТЦ = `S-40`–`S-42` + управление предметами. **УПЦ** — узел N-1: не
проектируется до расшифровки владельцем.
