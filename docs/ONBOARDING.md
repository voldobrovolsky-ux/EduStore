# Онбординг школы — включая оплату вне сайта

## Проблема
Школа оплатила **не через сайт** (прямой договор/счёт) → событие покупки не сработало →
организация в Флёрусе не создана автоматически тем флоу, что описан в продукте (шаг 1–2).
Нужно «зайти как админ школы», и тогда весь пайплайн работает.

## Решение (ключевой принцип): EduStore провижинит локальную орг ЛЕНИВО из Флёрус-claims
Сайтовая покупка — это **лишь один триггер** создания Флёрус-орг. Источник истины об
организациях и ролях — **Флёрус** (`florus_orgs[]` в токене). Значит:

- Для оффлайн-школы **создаём членство в Флёрусе вручную** (у вас Флёрус работает + admin-key).
- EduStore при первом входе админа **зеркалит** Флёрус-орг в свою БД (lookup-or-create
  `Organization{florusOrgId}`). Это и есть «активация» — без сайтовой покупки.

→ EduStore **не зависит** от события покупки. Зависит только от членства в Флёрус-орг.

## Runbook (вы, в Флёрусе)
1. **Создать орг школы** в Флёрусе: `POST /api/orgs {"name":"Гимназия №5"}` токеном учредителя
   (или через Флёрус-админку). Учредитель = `owner`.
2. **Сделать школьного админа членом орг с ролью `admin`** (provisioning/admin-path гайда §6):
   - есть Флёрус-аккаунт → добавить в орг с ролью `admin`;
   - нет → провижинить (name + role=`admin` + temp password, `must_change_password`), бинд по
     provisioning-QR (device flow `purpose=provision`).
3. **Админ входит в EduStore** (`edustore-flor-group.ru`) через Флёрус → токен несёт
   `florus_orgs[] = [{org_id, role:"admin"}]` → EduStore роутит в админ-кабинет.
4. EduStore на первом входе создаёт локальную `Organization(florusOrgId=org_id, name=org_name)`
   → админ создаёт структуру (предметы/классы), назначает staff→{завуч/методист/психолог},
   распределяет учителей. Пайплайн работает.

## Что строит EduStore (по этому контракту)
- OIDC-вход (BFF, см. ADR-0005) + **lazy-provision** локальной орг из claims.
- `Membership(florusUserId, orgId, florusRole, subRole)` — sub-роль назначает админ.
- Ручное создание структуры (предметы/классы) — стартовый объём (без PDF→КТП пайплайна).

**Нужно от вас для входа:** `FLOR_CLIENT_ID` (=`edustore`?), `FLOR_CLIENT_SECRET`, и точный
зарегистрированный `redirect_uri` (должен быть `https://edustore-flor-group.ru/api/auth/flor/callback`).
