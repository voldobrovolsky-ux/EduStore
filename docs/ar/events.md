> Нумерация сквозная по всей системе — см. [AR-PROTOCOL.md](../method/AR-PROTOCOL.md).
> Индекс всех реестров: [INDEX.md](./INDEX.md). Ворота: [G-CHECKS.md](../G-CHECKS.md). Линзы: [LENSES.md](../method/LENSES.md).

| № | Решение | Статус | Ворота | Линзы |
|---|---|---|---|---|
| AR-5 | Межмодульные факты — **только через transactional outbox** (`OutboxService.enqueue` в транзакции домена). Прямые импорты чужих сервисов и FK между параметрами запрещены (ADR-0001, PARAMETERS §4). | [РЕШЕНО] | G-4 | L-5, L-4 |
| AR-21 | Единый конверт `DomainEvent{id, type, occurredAt, workspaceId, correlationId, causationId, depth, actor, payload}`; tenant — в конверте, не в subject; `continuation()` наследует correlation и инкрементит depth. | [РЕШЕНО] | G-4 | L-4, L-11 |
| AR-22 | Защита каскадов: `MAX_CASCADE_DEPTH=12` (drop + лог), DLQ (`FAILED` при attempts≥8), inbox-дедуп `ProcessedEvent(eventId, consumer)`. Пять рычагов из исследования аналогов (PARAMETERS §1). | [РЕШЕНО] | G-4 | L-4, L-12 |
| AR-23 | **Единый канон имён событий: `<домен>.<агрегат>.<глаголПрош>.v<N>`** (решение владельца 2026-07-28). События `edustore.*` переименованы одним коммитом (шина in-process, внешних подписчиков нет; опубликованная история outbox — архив, не мигрируется). Версия обязательна. Ворота — линт G-16. | [РЕШЕНО] | G-16 | L-18, L-3 |
| AR-24 | **Каждый подписчик — через inbox, без исключений** (решение владельца 2026-07-28): дедуп `ProcessedEvent` навешивается централизованно при регистрации хендлера в `EventBus` (рядом с depth-guard), не вручную по месту. Цена — одна строка на обработку; защита от повторной доставки при будущем NATS. | [РЕШЕНО] | G-16 | L-4 |
| AR-25 | Чувствительные ПД (мед/соц/риски детей) — **тонкие события** (Event Notification): payload несёт id и тип, данные читаются по правам. Толстые (ECST) — для остального. | [РЕШЕНО] | нет: структурное (payload-контракты) | L-13, L-6 |
| AR-52 | **События контингента — публичный контракт**: тот же канон имён `<домен>.<агрегат>.<глаголПрош>.v<N>` (AR-23), транспорт-агностичный — in-process сейчас, NATS при втором рантайме (граница ввода — AR-10). Внешний сервис EduStore подписывается на тот же контракт, что и внутренние модули: дисциплина одна для одной школы и для маркетплейса, разница только в том, кто подключается. | [РЕШЕНО] | G-23, G-16 | L-6, L-4 |
