| AR-69 | **Экраны общие, действия гейтятся**: все шесть ролей v1 видят кабинеты календаря, расписания и журнала; различие ролей выражается доступностью **действий**, а не скрытием экранов. Право проверяется с первого дня, каталог прав пополняется в том же коммите (AR-35) — ретро-гейтинг ломает уже сложившиеся привычки пользователей и стоит дороже. Кабинет управления школой виден только модератору. | [РЕШЕНО] | G-10 | L-15, L-8 |
| AR-77 | **Единый паттерн кабинета модератора**: экран — сетка карточек; открытие — блюр фона + карточка в центре; действия — на открытой карточке. Опциональные параметры мастеров выбираются явно, включая отказ: кнопка «без литер» / «без групп», пустое поле выбором не считается (следствие AR-18). Превью произведения «параллели × литеры = N классов» показывается до подтверждения. | [РЕШЕНО] | G-33 | L-15, L-14 |
| AR-80 | **Дизайн-направление Schoolium** (решение владельца 2026-08-20): фиолетово-розовая гамма с обилием белого. Токены — `docs/design/tokens.json`, контраст всех пар «текст × фон» доказывается перечислением (G-37, WCAG 2.1: текст ≥4.5, UI ≥3.0). **Правило разведения**: брендовый розовый живёт только в интерактиве (кнопки, акценты, бейджи) и никогда не заливает строки данных; пастель маркеров пола — только в журнале контингента (проверка G-37 показала: заливки почти совпадают, различать их обязаны контекст и форма, не оттенок). Смысл не кодируется одним цветом: у отметок есть символ, у маркеров пола — позиция строки. | [РЕШЕНО] | G-37 | L-15, L-16 |
| AR-81 | **Навигационная оболочка — две раскладки, одна структура**: десктоп — постоянный левый сайдбар 240px (сворачиваемый до 72) + топбар 64px; мобайл — хедер 56px + нижний таб-бар из **пяти вкладок, одинаковых для всех шести ролей** (Классы · Предметы · Персонал · Расписание · Журнал). Кабинет модератора не становится шестой вкладкой и не создаёт отдельного меню: различие ролей выражается доступностью действий внутри экранов (AR-69), иначе два человека, обсуждая продукт, видят разные меню. Экраны входа показываются без оболочки. | [РЕШЕНО] | G-39 | L-15, L-14 |
| AR-82 | **Правила модалок**: вложенность не глубже двух уровней (карточка → QR-слой); на мобайле мастера и карточки — полноэкранные, выборы и поповеры — нижние листы; выход из мастера с введёнными данными требует подтверждения; ловушка фокуса и возврат фокуса обязательны. Третий уровень вложенности — признак того, что поток спроектирован неверно, а не сложного случая. | [РЕШЕНО] | G-39 | L-15, L-2 |
